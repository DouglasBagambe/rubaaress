# Admin Content Guide

## Sign In

Open `/studio`, sign in with the approved Sanity account, and choose the `Rubaare SS` project.

## Update School Contact Information

Open **Site Settings**. Edit the school name, motto, telephone, postal address, location, Google Maps links, footer introduction, or copyright text. Publish when ready.

## Change The Badge

Open **Site Settings**, replace **School badge**, enter clear alternative text, and publish.

## Edit Hero Slides

Open **Homepage**. In **Hero slides**, add, remove, reorder, enable, or disable slides. Each enabled slide needs a heading, image, and useful image alternative text.

## Edit Homepage Content

Open **Homepage**. Update welcome text, headteacher name and message, academic introduction, enrolment heading, news/events headings, school-life text, master-plan preview, and admissions button label.

## Create A New Annual Enrolment Record

Open **Current Enrolment** and create a new enrolment document. Enter the academic year, reporting date, and class rows. Do not enter totals; the website calculates totals automatically.

## Mark An Enrolment Record Current

Set the desired enrolment record status to **current** and publish. Archive old records where appropriate.

## Change Class Figures

Edit the class rows and enter non-negative whole numbers for female day, female boarding, male day, and male boarding.

## Publish Changes

Use Sanity's **Publish** action. The public site reads published content and keeps local fallback content if a CMS field is empty.

## Restore A Draft

Use Sanity document history or discard unpublished draft changes before publishing. If unsure, do not publish and ask a site administrator to review.
