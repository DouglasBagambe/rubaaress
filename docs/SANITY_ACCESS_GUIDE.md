# Sanity Access Guide

## Recommended Roles

- NileBit Labs administrator: full project and schema ownership.
- School content administrator: edit and publish school content, upload images, manage albums, downloads, enrolment, news and contact details.
- Optional school editor: draft content without deployment access.

## What School Administrators Need

- Sanity Studio access at `/studio`
- Permission to create, edit and publish content
- Permission to upload images and documents

## What They Do Not Need

- GitHub access
- Source-code access
- Vercel access
- Environment variables
- Billing or schema settings

## Invite Steps

1. Open the Sanity project dashboard for `Rubaare SS`.
2. Go to project members.
3. Invite the official school administrator email.
4. Assign the least-privileged content role available for editing and publishing.
5. Confirm they can sign in to `/studio` and publish a harmless test edit.
