# Gallery Admin Guide

## Create an Album

Open Studio, go to Gallery, then Albums. Create a new album, add the album title, short description, category, date or academic year when confirmed, and set visibility to public only when it is ready.

## Choose a Cover

After media has been added, choose a cover photo or video on the album. The cover appears on the gallery page and should clearly represent the album.

## Add Images

Go to Gallery, then Media. Create a media item, choose Image, upload the image, add useful alternative text, select the album, set the order, and publish when ready.

## Add Videos

Create a media item, choose Video, then select uploaded file, YouTube, or Vimeo. Add a poster image where possible and keep controls visible by default.

## Captions

Captions are optional. Add a caption only when it gives visitors useful context. Do not use filenames as captions.

## Change Order

Use Display order on media items. Lower numbers appear first.

## Remove From Public View

Unpublish a media item or set the album visibility to archived. Do not delete files unless you are certain they should be permanently removed.

## Archive an Album

Open the album and change Visibility to archived. Archived albums do not appear publicly.

## Publish Changes

Publish the album and each media item that should appear on the website.
